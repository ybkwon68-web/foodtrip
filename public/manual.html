  • 2정렬 — 최신순(기본) 또는 회차순으로 바꿀 수 있습니다.

검색 결과가 하나도 없으면 "검색 결과가 없습니다." 라는 안내가 뜹니다. 이때는 검색어를 짧게 줄이거나 지워보세요.

7관리 기능

편집 모드 켜기

관리자 전용

정보를 새로 등록하거나 고치려면 먼저 편집 모드로 로그인해야 합니다. 오른쪽 위 편집 모드 버튼을 누르면 로그인 창이 나타납니다.

  1. 화면 오른쪽 위 편집 모드 버튼을 클릭합니다.✎ 연필 아이콘이 그려진 버튼입니다.
  2. 관리자 비밀번호를 입력창에 넣습니다.비밀번호는 저장되지 않고, 로그인 세션만 유지됩니다.
  3. 로그인 버튼을 누르면 완료입니다.성공하면 "로그인되었습니다" 안내가 뜨고, 버튼이 편집 모드 끄기로 바뀝니다.

로그인 세션에는 유효 시간이 있습니다. 시간이 지나면 저장 시도할 때 "로그인이 만료되었습니다"라는 안내와 함께 편집 모드가 자동으로 꺼지니, 다시 로그인해주세요.

10관리 기능

새 회차 등록하기

관리자 전용 · 편집 모드 필요

편집 모드 상태에서만 나타나는 추가등록 버튼으로 들어갑니다. 회차 번호만 넣으면 기존에 이미 등록된 회차인지 먼저 확인해주고, 참고 URL을 넣으면 제목·식당 정보를 자동으로 채워줍니다.
